## 3. 排除项（都不是根因）

$ ip rule show
0:      from all lookup local
10000:  from all fwmark 0xc0000/0xd0000 lookup legacy_system
10500:  from all oif wlan0 uidrange 0-0 lookup wlan0
13000:  from all fwmark 0x10068/0x1ffff lookup wlan0
14000:  from all oif wlan0 lookup wlan0
19000:  from all fwmark 0x68/0x1ffff lookup wlan0
22000:  from all fwmark 0x0/0xffff lookup wlan0
23000:  from all fwmark 0x0/0xffff uidrange 0-0 lookup main
32000:  from all unreachable

$ ip route show table wlan0
default via 192.168.2.1 dev wlan0  proto static
192.168.2.0/24 dev wlan0  proto static  scope link

$ iptables-save | grep "dport 53"     # 空
$ iptables -t filter -S fw_OUTPUT | grep -E "owner|REJECT|DROP"   # 空

结论：路由表有 default、无 DNS 防火墙规则 → 失败发生在 socket()，与路由/DNS 配置无关。

## 4. 修复：补 aid_inet(3003) / aid_net_raw(3004) 组

# /data/debian/etc/group（sshd 用 initgroups() 读这里）
sdcard_rw:x:1015:svc
media_rw:x:1023:svc
aid_inet:x:3003:svc,_apt
aid_net_raw:x:3004:svc

# 重启 sshd 后重新登录
$ ssh -p 2222 svc@192.168.2.205 id
uid=2000(svc) gid=2000(svc) groups=2000(svc),1015(sdcard_rw),1023(media_rw),
  3003(aid_inet),3004(aid_net_raw)

$ ssh ... 'getent hosts deb.debian.org'
2a04:4e42:8c::644  debian.map.fastlydns.net deb.debian.org

$ ssh ... 'curl -o /dev/null -w "%{http_code} %{time_total}\n" http://deb.debian.org/debian/README'
200 0.996047s
$ ssh ... 'curl -o /dev/null -w "%{http_code}\n" https://deb.debian.org/debian/README'
200

## 5. apt（需要 root，svc 无 sudo：/data 为 nosuid）
