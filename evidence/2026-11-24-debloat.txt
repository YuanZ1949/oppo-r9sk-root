## 5. 恢复路径实验（三组，全部实测）

### 5.1 直接 pm install —— 被 ColorOS 拦，且表现为"卡死"

$ su -c 'pm uninstall -k --user 0 com.coloros.operationManual'   -> Success
$ su -c 'pm install -r -d /system/app/OppoOperationManual/OppoOperationManual.apk'
        pkg: /system/app/OppoOperationManual/OppoOperationManual.apk
        ... 300 s 无后续输出，超时
$ dumpsys window | grep mFocusedApp
        mFocusedApp=... com.android.packageinstaller/.OppoPackageInstallerActivity

不是死锁：OppoPackageInstallerActivity（ColorOS 安装确认页）被拉起，锁屏后面等人点。
解锁后 uiautomator 也读不到按钮（bottom_button_layout 无子节点），只能按坐标点：
  input keyevent 224; input swipe 540 1600 540 200 200; input keyevent 82; input tap 810 1839
点击后 InstallAppProgress -> package:/data/app/com.coloros.operationManual-1/base.apk（恢复成功）

### 5.2 PackageInstaller 会话 API —— 能装，但不恢复 user 0 安装态

$ pm install-create -r -g -S 203785          -> Success: created install session [955746753]
$ pm install-write -S 203785 955746753 base /data/local/tmp/x.apk -> Success: streamed
$ pm install-commit 955746753                -> Success
$ pm list packages | grep com.coloros.feedback -> （空）
$ pm list packages -u | grep com.coloros.feedback -> package:com.coloros.feedback   # 仍标记为未安装

### 5.3 改 package-restrictions.xml —— 唯一可脚本化的完整恢复（采用）

卸载状态记录形如（/data/system/users/0/package-restrictions.xml，136 行/8092 B）：
  <pkg name="com.coloros.browser" inst="false" stopped="true" nl="true" />

$ su -c 'sh /data/local/tmp/restore-one.sh com.coloros.feedback'
  pkg=com.coloros.feedback before=1 after=0 lines=135
  head=<?xml version='1.0' encoding='utf-8' standalone='yes' ?>
  xml-head=ok / xml-tail=ok
$ adb reboot && 等 30 s
$ pm list packages | grep feedback   -> package:com.coloros.feedback
$ pm path com.coloros.feedback       -> package:/data/app/com.coloros.feedback-1/base.apk   # 恢复成功

实验完成后已重新卸载 com.coloros.feedback，最终 installed=123。

## 6. 踩坑

1. `pm uninstall --user 0` 是"按用户卸载"，不是删 APK；APK 仍在 /system，/data 因 -k 保留。
2. `pm install` 在 ColorOS 上会被 OppoPackageInstallerActivity 接管；adb/PowerShell 侧表现为
   "卡在 pkg: 行"，实际是在等一次 UI 点击 → 别误判成 PackageManager 死锁。
3. 抢救时 `adb shell "su -c '...'"` 在 PowerShell 里引号会被吃掉（sed/grep 参数被拆断），
   凡是带引号的设备侧命令，一律写成脚本 push 过去执行。
4. uiautomator dump 抓不到 ColorOS 安装页的按钮节点（bottom_button_layout 为空），
   只能按坐标点；屏幕 1080x1920、density 480，安装按钮在 (810, 1839) 附近。
5. 卸载后首次重启，PC→ZT 曾出现 ~4 分钟不可达（ZT peers 走 relay，ARP 未建立）；
   从设备侧 `ping 192.168.193.4` 之后立刻恢复直连，随后两次重启均在 33 s 内可达 —— 属 ZT 路径协商，
   与去预装无关。

仍能解析；重跑一次（随后重启）才彻底消失。脚本本身幂等，发现残留直接重跑 `--apply` 即可。
