## 5. 插件激活问题（已解决）

# 只拷 index.js/tui.js（无 node_modules）时：
$ opencode auth list
Location plugins did not finish activating          # rc=1，约 13 s 放弃

# 原因：index.js 依赖外部包
$ head -5 index.js
// @bun
import { homedir as homedir6 } from "os";
import { Plugin } from "@opencode/plugin/effect";
import { Cause as Cause25, Effect as Effect46, Ref as Ref2 } from "effect";

# 补 node_modules（PC 同版本，52.5 MB / 3667 files → 解压后 64 MB）：
$ du -sh ~/.config/opencode
64M

# 之后 run 正常：
$ opencode run --model opencode/deepseek-v4.1-flash-free "reply with exactly: CHROOT_OK"
CHROOT_OK
rc=0 elapsed=23s
