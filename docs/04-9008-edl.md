# 04 · 9008 EDL：唯一可行路线

> **这是本项目中唯一能真正拿到持久 root 的方案。**
> 但它**当前被 USB 阻塞**，在 `07-blockers.md` 的检查通过之前，不要开始。
> 本文档是操作手册 + 风险清单，不是「照着点就完事」的教程。

---

## 0. 前置检查（缺一不可）

| 检查项 | 通过标准 | 不通过怎么办 |
| --- | --- | --- |
| 数据线 | 普通模式下插电脑有提示音，`adb devices` 能列出设备 | 换线（见 `07-blockers.md`） |
| OTG 转接头 | **必须拔掉** | OTG 会让手机进 Host 模式，9008 进不去 |
| 电量 | ≥ 50% | 先充电 |
| 固件版本 | 记住 `设置 → 关于手机` 里的 `R9sk_11_A.xx` | 刷机包必须匹配这个版本线 |
| 备份 | 照片/微信/通讯录已导出 | 9008 理论上不动 userdata，但**不要赌** |
| 电脑环境 | Windows 10/11，能装未签名驱动 | 关闭驱动签名强制或用测试模式 |

> ⚠️ **R9sk ≠ R9s ≠ R9st**。三者 `aboot` 不通用。买/下包时认准 `R9sk`。

---

## 1. 需要的四样东西

| 文件 | 作用 | 来源与可信度 |
| --- | --- | --- |
| **Qualcomm USB Driver**（如 v1.0.10065.1） | 让 Windows 把 9008 识别成 `Qualcomm HS-USB QDLoader 9008 (COMx)` | 高通官网 / 各刷机站转载，可信 |
| **R9sk 官方线刷包** | 提供分区表、`emmc_appsboot.mbn` 基线、`boot.img` | ONFIX / 机锋 / 移动叔叔 / ZOL，**需核对版本号** |
| **MsmDownloadTool**（授权版） | 原版需要 OPPO 内部账号才能点「开始」；流传的破解版绕过授权 | ⚠️ **来源不可信，见 §6** |
| **R9s/R9sk 专用 TWRP 包** | 含 `recovery.img` + 解锁版 `emmc_appsboot.mbn` | 7to / CSDN / ROM 乐园，**需核对机型** |

> 我在本机 `C:\MyFile` 扫过三层深度，**一个相关文件都没有**，需要从零准备。

## 2. 进入 9008

```
1. 手机完全关机（不是重启，是关机）
2. 按住 音量+ 和 音量- 不放
3. 插入 USB 线（连电脑）
4. 保持按住约 5 秒，然后松开
```

**判断标准**：

| 阶段 | 设备管理器显示 |
| --- | --- |
| 刚插入 | `QUSB_BULK` 或 `Qualcomm HS-USB QDLoader 9008 (COMx)`（未装驱动时可能带黄色感叹号） |
| 装好驱动 | `Qualcomm HS-USB QDLoader 9008 (COM3)` 之类，端口号记下来 |

如果**设备管理器毫无反应** → 物理层没通，回到 `07-blockers.md`，不要继续。

## 3. 刷写步骤（只动两个分区）

```
1. 先运行一次 MsmDownloadTool-0.exe（授权绕过），关闭
2. 打开 MsmDownloadTool.exe，「开始」按钮应可点击
3. 按 F5 进入分区选择界面
4. 全不选，只勾选：
      aboot     → 指向 TWRP 包里的 emmc_appsboot.mbn
      recovery  → 指向 TWRP 包里的 recovery.img
5. 取消「下载完成后自动重启」
6. 点「开始」，等待进度条走完（通常 1–3 分钟）
7. 断开 USB，手动进 Recovery：
      长按 音量- + 电源 约 15 秒
```

### 为什么只刷两个分区

- `aboot`：把锁定的引导替换成解锁版，让后续能进第三方 recovery / fastboot
- `recovery`：TWRP，用来刷 root 包和备份
- **不动 `boot` / `system` / `userdata`**：降低变砖和数据丢失风险

> 如果 TWRP 包里的 `emmc_appsboot.mbn` 与你的固件版本不匹配，**先别刷**。
> 版本错配是「刷完进不了 fastboot」的头号原因。

---

## 4. TWRP 里第一件事：备份

进 TWRP 后，**先备份再刷 root**：

```
Backup → 勾选：
  ☑ EFS        ← IMEI / 基带，丢了不可恢复
  ☑ Modem      ← 基带固件
  ☑ Persist    ← 传感器校准、指纹等
  ☑ Boot
```

备份存到外置 SD 卡或 OTG U 盘（如果 TWRP 支持），**不要只存内置存储**——
万一后面要格式化 data，内置备份一起没。

## 5. 刷 root

| 方案 | 适用性 | 说明 |
| --- | --- | --- |
| **SuperSU 2.82** | ✅ 最稳 | 老平台兼容性最好，但 2017 年后停更 |
| **Magisk 20.x / 21.x** | ⚠️ 可用 | 支持 Android 6，但模块生态有限；新版 Magisk 已放弃 Android 6 |
| 其他「一键 root 包」 | ❌ 不要用 | 来源不明，常捆绑推广 |

刷完重启，验证：

```bash
adb shell        # 或 Termux 里
su -c id         # 应返回 uid=0(root)
```

## 6. 风险清单（认真看）

| 风险 | 概率 | 后果 | 缓解 |
| --- | --- | --- | --- |
| **刷错 aboot 变砖** | 中 | 进不了 fastboot | 只要还能进 9008 就能救；版本号必须核对 |
| **破解版工具带毒** | 中高 | 电脑被植入木马 | **在虚拟机 / 断网环境跑**，别在主力机 |
| **线刷包版本不匹配** | 中 | 基带丢失、无法开机 | 严格按 `R9sk_11_A.xx` 找包 |
| **TWRP 不兼容** | 中 | 触摸失灵 / 无法挂载 | 换 R9sk 专用版本，别用 R9s 的 |
| **备份丢失** | 低 | IMEI 丢失，无法通话 | 先备份 efs/modem/persist 到外部存储 |
| **dm-verity 校验失败** | 中 | 开机卡 logo | 刷完 root 后可能需要禁用 verity（TWRP 选项） |
| **保修** | — | 2016 年机器，保修早过 | 无所谓 |

### 真正的致命点

**「连 9008 都进不去」** 才是不可救的。只要 9008 还能枚举，理论上任何分区错误都能重刷。
所以：

- 进 9008 之前，先确认**普通模式 USB 是通的**
- 如果普通模式都不通，9008 大概率也不通（同一组 D+/D-）

## 7. 救砖路径

| 症状 | 处理 |
| --- | --- |
| 卡 logo | 进 TWRP → 恢复 boot/system 备份，或重刷官方 boot |
| 进不了 fastboot | 重新进 9008，刷回官方 `aboot` |
| 完全黑砖 | 9008 + 官方完整线刷包（全分区） |
| 9008 也进不去 | 检查线/口/尾插；尾插损坏需拆机 |

---

## 8. root 之后立刻要做的事

1. **验证 root**：`su -c id`
2. **装 Termux 的 root 源**：`pkg install openvpn`（root 源里唯一相关的网络包）
3. **测 `/dev/tun`**：`su -c 'ls -l /dev/tun'` + 尝试 `openvpn` 建隧道
4. **再谈 ZeroTier**：官方无 Termux 包，需要自行交叉编译；先用 OpenVPN 验证 TUN 通路
5. **记录**：把 `su -c getprop` 的输出存一份，和 root 前对比
